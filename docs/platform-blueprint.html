BitBull Platform Blueprint

How the BitBull agent is put together today, how a family archive becomes a cinematic or playable experience, and the decisions that need your sign-off before it grows into the heritage platform.

1 · System map

One server, two engines, one workspace per project

Every request goes through the turn runner, which is the single place where policy enters: the base prompt, the likeness rule, the project's instructions and, when needed, a recap of history. The engines only ever see a working folder and the MCP servers that project has switched on.

2 · Heritage pipeline

From a suitcase of records to a finished experience

Three skills carry this today (archive-ingest, heritage-experience, atlas-studio). The grounding gate is the product's core invariant from the decision record: nothing about a named person is rendered unless a catalogued source says it.

5 · For scrutiny

Decisions to confirm, gaps and risks

Ordered by how much they shape the platform, not by effort.

Decide

Bringing photos to life vs. the Rev 3 rule

Your brief now includes animating old photos and dramatising them. The decision record said "reconstruct the ground, never the man": no generative depiction of real people. The default is ground-only, which animates the world around a photo but not the person in it.

Recommendation: keep ground-only for anything shareable; allow private-likeness only in private family projects, labelled, with the uploader confirming rights.

Gap

Grounding is still a prompt, not code

Rev 3 said the grounding rule must be enforced in code. Today it lives in the system prompt and the heritage-experience skill, which a model can ignore.

Next: a binding checker over beats.json and the final captions that refuses unbound names, dates and places, run as a server step, not as model advice.

Risk

The agent runs shell on your PC

With bypassPermissions the agent can run any command as you. Project folders keep files apart but are not a sandbox.

Before other users: one container per project (Docker), resource limits, and no host credentials inside it.

Risk

Family records flow into a third-party memory

Every turn is archived to Ditto, including what's read from uploads about living relatives. That sits under UK GDPR for anyone still alive.

Next: an archive switch per project (off, facts only, full), defaulting to facts only for heritage projects.

Gap

Atlas runner untested against a real export

Atlas doesn't publish the exported-spec field names, so atlas-run.mjs reads them defensively. Its MCP is alpha and can't run nodes yet.

Next: export one workflow (e.g. Cinema Studio 4.0 shot), run --inspect, and fix the field mapping in one sitting.

Gap

No spend controls on generation

Video and 3D nodes cost Atlas credits per run, and the agent can loop. The skills ask for confirmation before batches, but nothing enforces it.

Next: a per-project budget the server checks before atlas-run and MCP calls, shown in the project header.

Gap

Media storage won't scale on local disk

Uploads and generated video live in the project folder. Fine for one family; not for hosted use or for hours of film.

Later: object storage with signed URLs, plus a transcoding step for proxies and contact sheets.

Decide

Provenance labels

EU AI Act Art. 50 labelling applies to output that reaches EU residents. The skill writes labels into credits and sidecar files, but there's no C2PA signing yet.

Decide before the first shared experience; it's cheap to add at the assemble step.

6 · Suggested order

What to build next

  1. Settle the likeness policy, then write the grounding rule as a product invariant in the repo.
  2. Grounding checker in code over beats and captions, with a build-failing test across sample experiences (the simcheck pattern).
  3. Prove one shot end to end: export an Atlas workflow, run it through atlas-run, drop the clip into an EDL.
  4. Per-project archive switch and budget cap.
  5. Coding parity: diff view and undo from OpenCode snapshots, then approvals for risky commands.
  6. Container per project before anyone else uses it.
