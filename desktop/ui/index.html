Actions

First-time setup (creates the locked-down bitbull distro)

Downloads Canonical's Ubuntu 24.04 image for WSL and checks it against the published SHA256 before importing, so nothing else needs to be installed first. Needs Windows 11 with WSL 2 and a filled-in .env in the repo (copy .env.example). Takes a few minutes; output appears below.

First-time setup (BitBull's own Linux VM, or the Docker you already run)

Colima gives BitBull its own Linux VM that can only see BitBull's folder (~/Library/Application Support/BitBull); it is installed with Homebrew if missing (brew.sh). Needs macOS 13 or later. No keys are needed first: setup creates .env with a password for BitBull if there isn't one, and BitBull asks for your SayGM key and Ditto sign-in on its first screen. The first build takes about 10 minutes; output appears below.
